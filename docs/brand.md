# 심장달리기 시각 기준

심장달리기는 특정 행사나 제휴사에 의존하지 않는 독립 게임 이름과 시각 체계를
사용한다.

## 기본 팔레트

- 박동 코럴 `#D94F67`
- 딥 로즈 `#A82F49`
- 차콜 잉크 `#332028`
- 따뜻한 종이 `#FFF9F6`
- 소프트 피치 `#FFF0EA`

경기 트랙은 테라코타 `#CE6B59`, 옅은 그린 `#DCEBDC`, 웜 그레이
`#F2E6E1`로 구성한다. 팀 레인은 여러 색을 사용하되 하트와 수치 정보가 먼저
읽히도록 채도를 낮춘다.

## 타이포그래피

웹과 앱은 Pretendard를 사용한다. 큰 제목은 굵고 좁게, 상태와 수치에는
tabular 숫자를 사용한다. 영문 카테고리는 설명용 보조 정보에만 쓰고 게임 이름은
항상 붙여 쓴 `심장달리기`로 표기한다.

## 워드마크

하트 실루엣과 한 줄의 맥박선을 결합한 자체 SVG 마크와 `심장달리기` 텍스트를
사용한다. 외부 행사 로고, 제휴사 락업, 장소명은 게임 워드마크에 포함하지 않는다.

## 모션

박동 입력은 240ms 이내의 짧은 스케일 피드백, 트랙 이동은 180ms 감속 곡선,
결과 진입은 420ms의 위치·크기 전환을 사용한다. 장식 애니메이션은 미세하게
유지하며 `prefers-reduced-motion`을 존중한다.
