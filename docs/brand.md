# 브랜드 토큰과 표기

호스트 웹의 디자인 토큰은 《ㅊㅊㅊ 운동회》 홍보물에서 직접 추출했다.

## 색

| 토큰                | 값        | 출처                      |
| ------------------- | --------- | ------------------------- |
| `--moss`            | `#9b9443` | 포스터 배경 잔디          |
| `--moss-deep`       | `#7d7734` | 모스에서 파생, 주요 액션  |
| `--olive` / `--ink` | `#3e3b1b` | 소개 카드 배경            |
| `--cream`           | `#fbfbee` | 모든 타입과 로고          |
| `--paper`           | `#f6f4e6` | 크림에서 파생한 화면 바탕 |

경기 화면의 트랙만은 별도로 지정받은 팔레트를 유지한다 — 주로 `#bf673c`,
인필드 `#dceca1`, 바탕 `#e6dad1`, 트랙 내부 글씨 `#3b1b10`. 팀을 구분하는
여섯 레인 색도 채도를 낮춘 채 따로 둔다. 브랜드 색은 화면 크롬(바탕·타입·
버튼·헤더)을 맡고, 트랙은 그래픽 오브젝트로서 자기 팔레트를 갖는 구조다.

## 타이포그래피

홍보물의 카드 위계를 그대로 따른다.

1. `nuvook | LIVINGLIKEAGIRAFFE` 파트너 락업 — 작게, 자간 넓게
2. 큰 영문 카테고리 — `PHYSICAL` / `REHEARSAL`, 가는 굵기(300), 자간 좁게
3. 어깨번호 + 한글 세션명 — `³ 신체 운동 · 0km 이어달리기`
4. 본문과 크림 알약 칩

## 로고

세 개의 ㅊ 마크. 포스터 원본에서 배경을 걷어내
`apps/host/public/brand/ccc-logo.png`(792×308, 알파)로 두고, `.ccc-mark`에서
CSS 마스크로 쓰기 때문에 `currentColor`를 따라 어느 배경에서도 색이 맞는다.
글로브 엠블럼 변형과 고해상도 원본이 필요하면 주최 측 PNG를 받아 교체한다.

## 문구

세션 공식 표기는 `0km 이어달리기`이며 상위 행사는 `《ㅊㅊㅊ 운동회》`다.
'경쟁과 승패'를 앞세우지 않고 함께 움직이는 시간이라는 결을 유지한다.
